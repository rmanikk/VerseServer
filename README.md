
# VerseServer

VerseServer is the independent music infrastructure platform powering VerseHana.

## Responsibilities

- Music catalogue management
- Artist and album records
- Audio and artwork storage
- Artist song submissions
- Admin moderation and approval
- Secure music delivery APIs
- Integration with VerseHana

## Architecture

- Backend: Node.js, Express, TypeScript
- Database: PostgreSQL
- ORM: Prisma
- Dashboard: React, TypeScript
- Validation: Zod
- Storage: Cloud object storage

## Project Structure

- `apps/api` — Backend API
- `apps/dashboard` — Admin dashboard
- `packages/shared` — Shared types and validation
- `docs` — Project documentation

## Development

Install dependencies:

```bash
npm install
```
